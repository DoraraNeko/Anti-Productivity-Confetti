# Changelog

## 1.0.0

- Release the application as Anti-Productivity Confetti (APC).
- Add a click-through Windows desktop overlay with colorful confetti continuously falling from above the screen.
- Add cracker illustrations at the bottom corners and launch curved confetti bursts from both corners on key presses and mouse clicks.
- Place crackers and calculate burst arcs per monitor; briefly display crackers after input.
- Implement three cracker designs, selectable at runtime with F1/F2/F3.
- Set the pop/spring cracker as the default design and the live confetti limit to 10000 (50–20000).
- Support virtual-screen coordinates and exclude the overlay from screen capture.
- Add startup settings, bilingual manuals and specifications, and release packaging.
- Use Esc to exit.
