# Anti-Productivity Confetti (APC) 仕様書

## 1. 目的

Windows デスクトップ上にカラフルな紙吹雪を継続して表示し、キー入力やマウスクリックに応じて左右下端のクラッカーから紙片を発射する。

## 2. 動作環境と表示

- Windows 10 / Windows 11。
- 仮想デスクトップ全体を覆う、最前面・非アクティブ・マウス透過のレイヤードウィンドウを表示する。
- 仮想画面の物理ピクセル座標を使い、画面キャプチャからオーバーレイを除外する。
- モニターごとの表示範囲を列挙し、クラッカーの位置と発射高度を個々のモニターの範囲に基づいて決める。

## 3. 機能仕様

### 3.1 紙吹雪

- 紙片は画面上端より上で生成し、重力で画面を通過して下へ落ちる。
- 紙片は複数色、個別の寸法・回転・揺れを持つ。
- 低レベルキーボード／マウスフックがキー押下および左・右・中央クリックを検出する。入力を抑止せず、80 ms の間隔制限の後、メッセージキューへイベントを送る。
- 各モニターの左右下端に1つずつクラッカーを描画する。クラッカーは入力を検知した時だけ表示し、最後の入力から既定1秒後に消える。表示中に再度入力があれば表示時間を延長する。
- 入力イベントごとに各クラッカーから紙片を放射状に発射し、頂点はモニター高さの約35〜105%となる。初速と重力によって軌道は放物線になる。
- クラッカーは先細りの筒、斜めの色帯、開口部を持つ円錐形として描き、発射元が分かるようにする。
- 紙片数は設定された上限を超えない。画面外または寿命終了の粒子は破棄する。
- Esc キーで終了する。
- F1 / F2 / F3 で3種類のクラッカーデザインを実行中に切り替え、それぞれを比較できる。切り替え時にも紙吹雪を発射する。

### 3.2 設定

実行ファイルの隣の `settings.ini` を起動時に読み込む。存在しなければ既定値で作成する。欠落値には既定値を使い、不正値にも既定値を適用して警告を表示する。

| セクション | キー | 既定値 | 範囲 |
|---|---|---:|---:|
| Confetti | RainIntervalMs | 50 | 20〜1000 ミリ秒 |
| Confetti | PiecesPerCracker | 55 | 1〜200 個 |
| Confetti | CrackerVisibleMs | 1000 | 100〜2000 ミリ秒 |
| Confetti | CrackerStyle | 3 | 1〜3（1=紙コーン、2=箔巻きチューブ、3=ポップ・スプリング） |
| Confetti | MaxConfetti | 10000 | 50〜20000 個 |

### 3.3 実装

- C++17 / Win32 API。Visual Studio 2022 v143 ツールセット。
- 32-bit BGRA の DIB にプリマルチプライドアルファで紙片を描画し、`UpdateLayeredWindow` で合成する。
- 約16 ms のウィンドウタイマーで更新する。
- 入力フックは `CallNextHookEx` へイベントを引き継ぎ、入力をブロックしない。
- 画面キャプチャ・ファイルへの画面保存・ネットワーク通信は行わない。

## 4. ビルドと配布

- `MSBuild APC.vcxproj /t:Rebuild /p:Configuration=Release /p:Platform=x64`
- `APC.exe` と設定ファイルは `bin\x64\Release\` に出力する。
- `powershell -ExecutionPolicy Bypass -File scripts\package.ps1` で配布 zip と SHA-256 を `dist\` に作成する。
